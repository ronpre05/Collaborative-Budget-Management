# User Stories

These are user stories that will aid our development process. During each sprint, the next highest priority tasks will be assigned and stories will be ticked off until there are no more left to complete. Story points represent the amount of work the tasks should take, and its priority is how important it is to have in the software.

They have been roughly split up into sections so that they are kept with like stories and more can be added without newer stories looking out of place in the list. These sections don't relate to how the software will be created. They are also numbered so that we can keep track of them during development. The numbers don't represent anything else such as priority or order etc. Below are the links to each section.
