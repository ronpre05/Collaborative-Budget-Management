
This sequence diagram outlines the workflow for managing a project in a collaborative budget management system. 
The coordinator performs various tasks to set up and manage the project, while the system and database handle data storage and retrieval. 
The steps include creating a project, inviting partners, entering costs, reviewing budget details, and updating metadata.

##Participants
Coordinator: The user responsible for creating and managing the project.
System: The application interface that facilitates user interactions and processes requests.
Database: The data storage component that saves and retrieves information as needed.
