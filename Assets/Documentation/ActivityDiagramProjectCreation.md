# Activity Diagram for Project Creation

This diagram represents the steps required during the creation of a project.

## Process

The user prompts the system to create a project, and chooses a template. From the template selected, the front and back-end are created, including the tables that will be used for the project.

The user is then prompted to input metadata relevant to the project, budget, work-packages, categories. After all the meta-data is inputted, the database will then be updated with all relevant information.

Then the front-end will query the database, and all UI components will update to reflect the database changes.
