# Coding Conventions

1. Variable names should be meaningful
2. Variable names should be written in camel case e.g. firstName
3. Curly braces will be on a new line
4. Else statements on new lines
5. Each class and function should have a brief description of its functionality, above written in a comment
6. Comments should be written where code isn't as self explantory
7. Class names should be written in the following format: ClassName
8. Function names should be written in camel case
9. Avoid any deep nesting of code
10. Code shouldn't be repeated
